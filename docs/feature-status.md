# 记录方式现状

截至 2026-11-16。Android 与 Web 共用同一套离线编辑器。正文直接显示排版后的内容；编辑结果仍保存为加密的 Markdown 操作，便于离线同步和 Obsidian 文本同步。

| 方式 | 当前实现 | 边界 |
| --- | --- | --- |
| 文字 | 直接编辑正文；底部 T 切换到 H1、H2、粗体、斜体、下划线、删除线、序号/无序列表、引用、分割线和对齐工具；表情由系统键盘输入 | 支持常见段落、标题、行内代码和链接。 |
| Markdown、待办项 | 打开笔记时渲染 Markdown；输入 `- `、`1. `、`# `、`> ` 等前缀时直接转换；非空待办项或引用行按回车续建，空行按回车退出，空项按退格删除，Shift+回车软换行 | 正文中的清单属于笔记内容，不会混入独立待办页。复杂嵌套 Markdown 的编辑尚未完整覆盖。 |
| 独立待办 | 底部待办页展示清单卡片、完成进度和可展开的子项；底部输入层支持回车续加、勾选与设置日期 | 日期时间保存在加密数据中，当前没有后台系统通知。 |
| 表格 | 在文字工具栏插入，可视化单元格直接编辑，空白行列等宽 | 暂无添加、删除行列的控件。 |
| 图片、拍照 | 一个图片按钮提供相册和拍照选项；图片显示在正文中，不显示文件名；点选后可注释、绘画、缩放、复制或删除 | 相机入口依赖设备及系统选择器。 |
| 绘图 | 全屏点阵画布；铅笔、毛笔、荧光笔、钢笔、橡皮、颜色、粗细、撤销和重做；点选正文中的绘图后可继续修改 | 以 PNG 栅格图重新打开，暂无图层。 |
| 思维笔记与内嵌导图 | 新建时可选独立思维笔记，直接进入居中的双侧节点画布；也可在普通笔记内插入导图。一份结构可切换大纲和导图两种视图；只有一个中心主题。大纲支持回车续建、缩进与提升；导图可点选节点并编辑文字、添加同级或子级、删除 | 独立思维笔记以 Markdown 大纲加密同步；内嵌导图保存为 SVG 附件。暂无拖拽改序；旧版无大纲数据的 SVG 只能作为图片操作。 |
| 录音 | 设备录音或选择音频，正文内播放 | 录音权限和可用性依赖设备。 |
| 附件 | 系统文件选择器，正文内下载；单个文件上限 5 MiB | 附件本机加密保存；启用同步后上传密文到 Docker 服务。 |

正文不显示内部附件标记；Obsidian 插件只同步普通笔记，不同步待办和思维导图。笔记以标题命名，ID 保存在属性中。图片、录音和普通文件解密到所选目录的 `_attachments/`，并在笔记中使用本地链接。密码条目不导出明文，仍保留 `surge-blob:` 引用。插件同步笔记文本和所属分类，但不创建空分类目录。

笔记支持列表、宫格、历史版本恢复、置顶、移动分类和回收站。长按卡片可多选，并批量置顶、移动或删除。回收站可以单项移除或一键清空：本机删除旧操作和独占附件，跨设备同步加密的删除标记；已上传的旧密文仍保留在 Docker 服务端的追加日志和附件存储中，清空回收站不等于擦除服务器历史。每篇笔记可选背景，编辑内页、列表和宫格中显示对应颜色；背景也作为加密字段同步。置顶笔记排在列表前面，回收站从设置进入。空白新建后直接返回不会留下笔记。毛玻璃默认开启。设置中的更新检查固定查询 Surge 的 GitHub 仓库。

思维导图的双视图与移动端主题操作参考[幕布快速上手](https://mubu.com/help/50)、[一键转换说明](https://mubu.com/help/11)和[思维导图编辑说明](https://mubu.com/help/28)。Surge 独立实现界面和数据格式；唯一中心主题在大纲中按回车时创建子主题，其余主题按回车创建同级主题。

待办和引用的回车规则参考 [Apple 备忘录列表操作](https://support.apple.com/en-lamr/guide/notes/apd93c815aa0/mac)与 [Google Keep 清单操作](https://support.google.com/keep/answer/16914649?hl=en)。Android 客户端关闭整个 WebView 的缩放手势，Web 端设置固定页面缩放；导图画布仍可平移。实现依据 [Android WebSettings](https://developer.android.com/reference/android/webkit/WebSettings) 和 [viewport 设置](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/meta/name/viewport)。
