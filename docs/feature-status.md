# 记录方式现状

截至 2026-11-15。Android 与 Web 共用同一套离线编辑器。正文直接显示排版后的内容；编辑结果仍保存为加密的 Markdown 操作，便于离线同步和 Obsidian 文本同步。

| 方式 | 当前实现 | 边界 |
| --- | --- | --- |
| 文字、Emoji | 直接编辑正文；表情插入光标位置 | 当前支持常见段落、标题、粗体、斜体、行内代码、链接和引用的显示与编辑。 |
| Markdown、待办 | 打开笔记时渲染 Markdown；输入 `- `、`1. `、`# `、`> ` 等前缀时直接转换；待办在正文中勾选 | 复杂嵌套 Markdown 的编辑尚未完整覆盖。 |
| 表格 | 可视化单元格直接编辑 | 暂无添加、删除行列的控件。 |
| LaTeX 公式 | KaTeX 原位渲染，双击可修改公式 | 需在公式弹窗中输入 LaTeX 源码。 |
| 图片、拍照 | 系统图片选择器与相机入口，图片显示在正文中 | 相机入口依赖设备及系统选择器。 |
| 绘图 | 全屏点阵画布；铅笔、毛笔、荧光笔、钢笔、橡皮、颜色、粗细、撤销和重做；保存后可在正文点击“编辑绘图”继续修改 | 以 PNG 栅格图重新打开，暂无图层。 |
| 思维导图 | 由缩进大纲生成 SVG 并显示在正文中 | 暂无拖拽式节点编辑。 |
| 录音 | 设备录音或选择音频，正文内播放 | 录音权限和可用性依赖设备。 |
| 附件 | 系统文件选择器，正文内下载；单个文件上限 5 MiB | 附件本机加密保存；启用同步后上传密文到 Docker 服务。 |
| 密码条目 | 名称、账号、密码作为加密附件存入笔记，可复制密码 | 没有自动填充或独立密码库。 |

正文不显示内部附件标记；Obsidian 文本同步仍保留 `surge-blob:` 引用。Obsidian 插件目前同步笔记文本和所属分类，不创建空分类目录，也不下载或渲染二进制附件。

笔记支持列表、宫格、历史版本恢复、置顶和回收站。置顶笔记排在列表前面，回收站从设置进入。空白新建后直接返回不会留下笔记。毛玻璃默认开启。分类和附件相关实现见 [客户端逻辑](../web/app.mjs)、[富文本转换](../web/rich-editor.mjs)、[界面](../web/index.html)、[加密存储](../web/db.mjs) 与 [服务端接口](../server/index.mjs)。
